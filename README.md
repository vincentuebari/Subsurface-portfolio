# Subsurface Portfolio

Self-directed reservoir engineering programme — Vincent Uebari, Port Harcourt.

Working from fundamentals through to a defensible history match on real field
data, using OPM Flow and ResInsight. Everything here is my own work, including
the mistakes, which are left in deliberately.

- `GLOSSARY.md` — working definitions, written from memory and corrected
- `assessments/` — baseline diagnostic and module tests
- `01-foundations/` — units, notation, rock and fluid fundamentals
